# 🥋 Welcome to the Dojo

This is **not** a passive learning community. It is an active engineering node.

## Rule 1 — Strict self-reliance

Do not ask for solutions. Ask for **debugging vectors**: what you tried, the exact error, shapes, and notebook cell.

Use `@DojoBot` in `#ask-track-1` / `#ask-track-2` for Socratic help. It will **not** write your code.

## Rule 2 — Complete integrity

Lesson completion uses **cryptographic proofs** (`PASS-*` lines) bound to **your** Discord ID.

Copying another student's hash = automatic failure + **permanent ban** from this server and future cohorts.

## Rule 3 — Compute discipline

Run `dojo-profile` before you claim heavy tracks. Respect your tier (`Tier-Lightweight` / `Tier-Standard` / `Tier-Gpu`).

Do not run Atari or large LLM jobs on hardware the profiler did not approve.
